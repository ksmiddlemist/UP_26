# ROOMIE — сервис подбора соседей для совместной аренды жилья

## Концепция и проблема

ROOMIE — учебный проект веб-сервиса для людей, которые ищут соседа для совместной аренды. На площадках объявлений удобно искать жильё, а в общих чатах сложно заранее понять, подойдёт ли будущий сосед по бюджету, режиму дня и бытовым привычкам. ROOMIE помогает подобрать кандидатов по этим критериям и открывает контакты после взаимного лайка.

## Основной функционал первой версии

- **Вход и профиль.** Вход по одноразовому коду из письма, заполнение анкеты с фотографией, контактами и бытовыми предпочтениями.
- **Поиск соседей.** Подбор по городу, при необходимости по району, с фильтрами по бюджету, режиму дня, отношению к курению, наличию животных, типу и сроку аренды.
- **Лайки и мэтчи.** Возможность поставить лайк, ответить на входящий лайк и увидеть контакты друг друга в разделе «Мэтчи» при взаимной симпатии.
- **Управление поиском.** Возможность скрыть свою анкету из выдачи после того, как сосед найден, с сохранением прежних мэтчей.
- **Модерация и поддержка.** Жалобы на анкеты, их обработка администратором и восстановление доступа после проверки учётной записи.

## Что сделано в рамках проекта

Проработаны требования и сценарии использования, подготовлены техническое задание и технический проект. В репозитории собраны документы и диаграммы, которые описывают функции ROOMIE, структуру данных, взаимодействие компонентов и развёртывание сервиса.
